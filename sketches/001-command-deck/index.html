§ CORE PRIMITIVES

How a collective thinks

Every participant — silicon or carbon — talks through the same hub. No routing logic branches on what you are. That single design decision is what makes the rest possible.

PARTICIPANT//AGENT

Agents run the loop

LLM-driven participants call tools, receive results, and repeat — autonomously, for as long as the work needs.

CONVERSATION//TREE

Branching message trees

Conversations aren't arrays. They're trees — edit, re-run, prune, compact. Every historical node stays recoverable.

AUTH//FAIL-CLOSED

Approvals bubble up

AuthEngine is a pure predicate. Requests that need authority rise to an authorized approver — or fail closed. Never open.

§ SERVICE SDK

Any npm module can enlist

Services are ordinary participants with code for brains. Export an object, get scoped storage, messaging, and tool calls with auth enforced.

sentinel-service.ts
import type { LegionService } from '@legion/core';

export const service: LegionService = {
  async start(ctx) {
    // watch the collective, act on events
    ctx.onMessage('deploy-finished', async (msg) => {
      await ctx.communicate('assistant', `Build ${msg.body.sha} is green ✓`);
    });
  },
  async stop() {},
};
